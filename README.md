# **Αντίστροφοι πολυωνυμικοί συντελεστές Ci_, Di_ για τα πολυώνυμα x=x(E-E0,N-N0) και y=y(E-E0,N-N0) από τα πολυώνυμα ΟΚΧΕ** 

Χατζηλιόντος Χριστόδουλος (ΑΠΘ, ΑΤΜ, ΑΜΕ 6289, chatzilc@topo.auth.gr, Οκτώβριος 2026)

Η παρούσα εργασία επιχειρεί να καλύψει το κενό της μη ύπαρξης σταθερών πολυωνυμικών συντελεστών για τον υπολογισμό των συντεταγμένων (x,y) ενός σημείου σε προβολικό σύστημα HATT της ΓΥΣ όταν είναι γνωστές οι συντεταγμένες (E,N) του σημείου στο προβολικό σύστημα ΕΓΣΑ 87. Οι νέοι συντελεστές συμβολίζονται με Ci_ και Di_, όπου i=0,1,…,5, χρησιμοποιούνται στις σχέσεις x = x(E-E0,N-N0) = x(E_,N_) = C0 + C1 E_ + C2 N_ + C3 E_^2 + C4 N_^2 + C5 E_ N_, y = y(E-E0,N-N0) = y(E_,N_) = D0 + D1 E_ + D2 N_ + D3 E_^2 + D4 N_^2 + D5 E_ N_ και υπολογίζονται από συγκεκριμένες αλγεβρικές εξισώσεις στις οποίες συμμετέχουν μόνο οι πολυωνυμικοί συντελεστές Ai και Bi του ΟΚΧΕ. Εξάγωνται οι σχέσεις Ci_=Ci_(Aj,Bj), Di_=Di_(Aj,Bj), όπου j=0,1,…,5, και εφαρμόζονται για το φύλλο χάρτου Λαμία. Το RMS (υπολογιζόμενο σε κάναβο 121 σημείων από (-25000, -25000) έως (+25000, +25000)) των νέων σχέσεων κατά x και y είναι μικρότερο του 1mm σε όλα τα ΦΧ εκτός από τα ΦΧ 025, 059, 77Α, 243 και 254, επί συνόλου 390 ΦΧ. Αυτή η πολύ καλή εσωτερική ακρίβεια δεν βελτιώνει την εξωτερική ακρίβεια μετατροπής μεταξύ των 2 προβολικών συστημάτων, πρέπει να έχουμε κατά νου ότι υπερισχύει η αβεβαιότητα των 10-15εκ που έδωσε ο ΟΚΧΕ. Η ύπαρξη των σχέσεων x=x(E,N) και y=y(E,N) αναμένεται να μειώσει τον υπολογιστικό φόρτο μετατροπής από (E,N) σε (x,y), διότι πρόκειται για υπολογισμό ενός σταδίου και με δεδομένο πως μέχρι σήμερα εφαρμόζονται αριθμητικοί επαναληπτικοί αλγόριθμοι. Σε κάθε περίπτωση δεν παρέχεται καμμία εγγύηση για τους υπολογισμένους συντελεστές, ο χρήστης καλείται να ελέγξει την ορθότητά τους πριν από την χρήση τους.
